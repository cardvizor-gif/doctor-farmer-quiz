# Анализ шаблона заявки на поставку

Шаблон `Заявка_шаблон.xlsx` содержит одну рабочую вкладку, рассчитанную на две печатные страницы. В верхней части расположены реквизиты заявки: дата, покупатель, сегмент, ФИО менеджера, условия и срок оплаты, комплект документов для поставки, срок поставки и признак работы в ЭДО с выбором провайдера.

Номенклатурная часть — табличная форма из пяти колонок: «№ п/п», «Наименование товара», «Кол-во», «Цена, руб.», «Сумма, руб.». В шаблоне подготовлено 33 строки. Для реализации в кабинете целесообразно хранить строки заявки отдельно от её заголовка, зафиксировав на момент сохранения название товара, единицу/количество, цену и сумму. Так история отгрузок не будет меняться при последующем обновлении прайса.

## Предлагаемый первый контур

1. Менеджер создаёт заявку из карточки хозяйства или вручную выбирает хозяйство; покупатель и контактные данные подставляются автоматически.
2. ФИО менеджера подставляется из текущей сессии. Поля сегмента, оплаты, сроков, документов и ЭДО остаются редактируемыми.
3. Номенклатура добавляется из сохранённого КП либо построчно из каталога, с контролем количества, цены и итоговой суммы.
4. Заявка сохраняется с неизменяемым снимком реквизитов и строк. Менеджер видит только свои заявки, администратор — заявки всей команды.
5. Для бухгалтерии формируется печатный документ, повторяющий логику приложенного шаблона; история отгрузок отображает статус, дату, количество, цену и итог по каждой заявке.

## Предлагаемая структура данных

| Сущность | Сохраняемые данные | Назначение |
|---|---|---|
| Заявка | номер, дата, хозяйство, снимок покупателя, менеджер, сегмент, условия оплаты и поставки, сроки, ЭДО, статус, итог | единый документ для менеджера и бухгалтерии |
| Строка заявки | наименование, единица измерения, заказанное количество, согласованная цена, сумма | неизменяемый снимок номенклатуры на дату заявки |
| Отгрузка | заявка, дата, номер документа, статус, комментарий | позволяет отразить частичную или полную отгрузку |
| Строка отгрузки | товар, отгруженное количество, фактическая цена, сумма | фактическая история поставок без изменения исходной заявки |

Одна заявка может иметь несколько отгрузок: например, поставка частями или изменение фактической цены на отдельную партию. Сумма и количество в истории считаются по строкам отгрузки, а в карточке заявки отображается сравнение «заказано / отгружено / остаток». Снимок реквизитов в заявке не меняется, если позднее обновить карточку хозяйства или прайс.

## Права и отчёты

Менеджер создаёт, редактирует до передачи в бухгалтерию и видит только собственные заявки. После статуса «Передана в бухгалтерию» исходная номенклатура фиксируется. Администратор видит заявки и историю отгрузок всей команды, может сформировать общий Excel-отчёт. Печатная форма будет заполняться по образцу без обращения к внешним сервисам.

В первом релизе историю отгрузок разумно вводить вручную: дата, номер УПД/накладной, позиции, фактические количество и цена. Автоматическая сверка с 1С или другой учётной системой возможна позже, если появится согласованный способ интеграции.

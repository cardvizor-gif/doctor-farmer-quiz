# Восстановление Doctor Farmer из GitHub

## Назначение резервной копии

Актуальный исходный код Doctor Farmer хранится в ветке `main` репозитория `cardvizor-gif/doctor-farmer-quiz`. Если текущий сервер или IP-адрес станет недоступен, проект можно развернуть заново на другом сервере, используя этот репозиторий.

> GitHub сохраняет исходный код, конфигурацию сборки, миграции и документацию. Он **не сохраняет** рабочую базу данных, файлы-вложения пользователей и секреты окружения.

## Быстрое восстановление кода

На новом Ubuntu-сервере с Node.js, pnpm и Git:

```bash
git clone https://github.com/cardvizor-gif/doctor-farmer-quiz.git
cd doctor-farmer-quiz
pnpm install
pnpm run build
pm2 start dist/index.js --name doctor-farmer
pm2 save
```

Перед запуском полноценного рабочего кабинета необходимо создать защищённый серверный файл окружения и настроить собственные сервисы данных.

## Что резервировать отдельно

| Компонент | Что нужно хранить отдельно от GitHub | Причина |
|---|---|---|
| База данных | Регулярный дамп MySQL/TiDB и параметры подключения | В базе находятся хозяйства, КП, заявки, обращения, пользователи и статусы. |
| Файловое хранилище | Резервная копия S3-совместимого хранилища и его ключей | В нём находятся приложенные к обращениям файлы. |
| Переменные окружения | Защищённая копия `.env` или конфигурации процесса | Включает строку базы, секрет сессий, настройки OAuth и хранилища; значения нельзя коммитить в GitHub. |
| Домен и HTTPS | Данные DNS/SSL-конфигурации | Для защищённого входа и работы cookie требуется HTTPS. |

## Проверка перед аварийным восстановлением

1. Откройте репозиторий и убедитесь, что ветка `main` содержит последний коммит.
2. Создайте новый сервер и выполните команды из раздела «Быстрое восстановление кода».
3. Добавьте конфигурацию окружения только через защищённый файл на сервере, а не в репозиторий.
4. Восстановите базу данных и файлы из отдельных резервных копий.
5. Примените миграции только после проверки, что подключение ведёт к правильной восстановленной базе.
6. Запустите приложение через `pm2` и проверьте гостевой, сотруднический и административный сценарии.

## Текущее решение

Самостоятельный сервер `193.233.201.76` используется как техническая копия. Основной способ сохранения исходного кода — GitHub. Для полноценной автономной работы любого нового сервера потребуется настроить собственные базу данных, файловое хранилище, HTTPS и доступ владельца.
